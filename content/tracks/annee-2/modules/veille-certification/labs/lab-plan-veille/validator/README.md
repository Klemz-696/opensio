# Validateur : Élaboration d'un Plan de Veille Technologique et Synthèse d'Actualité IT

Ce répertoire contient le script de validation autonome (`validate.mjs`) et les fixtures de test pour l'atelier de veille technologique.

## Critères d'Évaluation (100 points)
1. **`veille_plan_structure_and_theme` (25 pts)** : Définition de la thématique, des outils et de la fréquence de veille.
2. **`veille_sources_diversity_and_quality` (25 pts)** : Au moins 4 sources de veille diversifiées avec URLs valides et canaux.
3. **`veille_synthese_structure_and_metadata` (25 pts)** : Titre explicite et métadonnées (Date, Source officielle, Auteur).
4. **`veille_synthese_impact_and_recommendations` (25 pts)** : Résumé technique, analyse d'impact sur le SI et préconisations d'action.

## Utilisation
```bash
node validator/validate.mjs /chemin/vers/repertoire
```
