# Validateur : Structuration d'un Product Backlog et Planification de Sprint Agile

Ce répertoire contient le script de validation autonome (`validate.mjs`) et les fixtures de test pour l'atelier de backlog et planification de Sprint.

## Critères d'Évaluation (100 points)
1. **`product_backlog_structure_and_stories` (25 pts)** : Définition d'au moins 4 User Stories avec formulation standard (as_a, i_want, so_that).
2. **`acceptance_criteria_and_story_points` (25 pts)** : Critères d'acceptation testables et estimations en Story Points (Fibonacci).
3. **`sprint_goal_and_capacity_definition` (25 pts)** : Définition de l'objectif métier (sprint_goal) et capacité de l'équipe (20 SP).
4. **`sprint_backlog_selection_and_velocity_fit` (25 pts)** : Sélection cohérente de stories respectant la capacité (15-20 SP).

## Utilisation
```bash
node validator/validate.mjs /chemin/vers/repertoire
```
